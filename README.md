## 🌟 Key Features & Architecture

- **Audience Persona Switcher**: Instant contextual switching between *Enterprises & Hirers*, *Software & Digital Engineering*, and *Job Seekers*.
- **Interactive Global Capability Center (GCC) Cost & Headcount Calculator**: Real-time estimations of team scaling, savings, and operational timelines.
- **Enterprise Talent Search & Rate Matrix**: Filter senior tech talent by niche skillsets (Full-Stack, Cloud Architecture, AI/ML, Data Engineering).
- **Interactive BOT (Build-Operate-Transfer) Visualizer**: Step-by-step roadmap demonstrating setup, governance, ramp-up, and asset transfer.
- **Dynamic Case Study Filter & Metrics Showcase**: Case studies with verified business ROI and client outcomes.
- **Modern Responsive UI**: Custom glassmorphism, dynamic glowing ambient backgrounds, smooth animations, and high accessibility.

## 💻 How to Run Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- Git

### Installation & Development

```bash
# 1. Clone the repository
git clone https://github.com/SamudralaHitesh/hirexa-solutions-redesign.git

# 2. Navigate to project folder
cd hirexa-solutions-redesign

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

Alternatively, you can simply open `index.html` directly in any modern web browser.
